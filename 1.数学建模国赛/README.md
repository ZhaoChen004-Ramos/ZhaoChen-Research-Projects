# 碳化硅外延层厚度的确定

基于红外干涉法无损伤测量 SiC 外延层厚度。从薄膜干涉建模、菲涅尔公式折射率反演、随机森林预测到多光束干涉边界判定，构成完整求解管线。

---

## 问题一：双光束薄膜干涉模型

仅考虑外延层上下表面各一次反射与透射，推导厚度公式：

```
d = k * lambda / (2 * sqrt(n1^2 - sin^2(theta0)))
```

---

## 问题二：双光束模型求解

利用菲涅尔公式建立 R 与 n1 的非线性关系，通过 fsolve 逐点求解 7000+ 数据点。
波峰检测：区间截断 + 局部极大值搜索定位 4 个波峰。牛顿法厚度结果 ~11.06 um。

随机森林回归解决牛顿法在高反射率区折射率偏高（~80）的问题，厚度结果 ~14.40 um。

---

## 问题三：多光束干涉边界判定

等比数列求和 + Stokes 倒逆关系推导 Airy 函数，一元二次方程解析求内壁反射率 rho，
边界判定 rho > 0.05 为多光束干涉。双光束波数范围 936.27-944.95 cm^-1。

