# 碳化硅外延层厚度的确定

基于红外干涉法无损伤测量 SiC 外延层厚度。从薄膜干涉建模、菲涅尔公式折射率反演、随机森林预测到多光束干涉边界判定，构成完整求解管线。

---

## 问题一：双光束薄膜干涉模型

仅考虑外延层上下表面各一次反射与透射，推导厚度公式：

```
d = k * lambda / (2 * sqrt(n1^2 - sin^2(theta0)))
```

k 为级数，lambda 为波长，n1 为折射率，theta0 为入射角。

---

## 问题二：双光束模型求解

### 牛顿迭代法求折射率

利用菲涅尔公式建立 R 与 n1 的非线性关系，通过 fsolve 逐点求解 7000+ 数据点。

波峰检测与级数确定：区间截断 + 局部极大值搜索定位 4 个波峰，利用相邻峰波长计算级数 k。

厚度结果：~ 11.06 um（算术平均）。组内精密度良好，组间差异显著（入射角敏感）。

### 随机森林回归修正折射率

解决牛顿法在高反射率区折射率偏高（~80）的问题。

| 阶段 | 细节 |
|------|------|
| 预处理 | 异常值过滤 + StandardScaler 标准化 |
| 特征 | [波数, 反射率] 二维特征，8:2 划分 |
| 标签 | 折射率限制 [2.0, 5.5] |
| 模型 | RandomForestRegressor(150, depth=10) |
| 评估 | R2 ~ 0.99，RMSE ~ 0.10 |

厚度结果：10 deg：~14.40 um，15 deg：~14.05 um，组间差异不显著。

---

## 问题三：多光束干涉边界判定

等比数列求和 + Stokes 倒逆关系推导 Airy 函数：

```
R(rho, d_psi) = 1 / (1 + (4*rho/(1-rho)^2) * sin^2(d_psi/2))
```

求解流程：
1. m*lambda_m 参数标定（附件3：26.2505 um，附件4：26.0334 um）
2. 逐点计算相位差
3. 一元二次方程解析求内壁反射率 rho（闭式解，非迭代）
4. 边界判定：rho > 0.05 为多光束干涉

结论：双光束波数范围 936.27-944.95 cm^-1，剔除多光束主导波段可提升精度。

## 代码管线

```
光谱数据 (.xlsx)
  +-- 可视化脚本             数据探索
  +-- 菲涅尔公式折射率求解.py  fsolve 逐点求折射率（7000+ 点）
  +-- 波峰确定及厚度计算.py    峰检测 + 级数 + 厚度
  +-- 随机森林预测折射率.py    ML 管线：训练 -> 评估 -> 预测 -> 厚度
  +-- 内壁反射率求解.py        m*lambda_m -> 解析求根 -> 边界判定
```

各脚本亮点：菲涅尔求解器函数式封装 + 7000+ 批量；随机森林完整 ML 管线 + 可复用预测函数；内壁反射率闭式解析求解 + 自动边界判定。
