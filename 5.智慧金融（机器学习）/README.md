## 项目简介

本项目使用 **K-Means 聚类算法**对银行信用卡客户数据进行聚类分析，结合 **PCA 主成分分析**降维，帮助银行工作人员筛选潜在投资人群，实现**智慧金融**场景下的客户分群。

通过对客户的消费行为、信用额度、分期还款记录等多维特征进行无监督学习，将客户分为不同群体，为银行的精准营销和客户关系管理提供数据支持。

## 算法概述

### K-Means 聚类

K-Means 是一种迭代优化算法，将数据集划分为 K 个簇，使簇内数据点相似度最大化、簇间相似度最小化。

**核心步骤：**

1. **初始化质心：** 随机选择 K 个数据点作为初始聚类中心
2. **分配数据点：** 计算每个点到各质心的欧氏距离，分配到最近的簇
3. **更新质心：** 计算每个簇内点的均值，作为新的质心位置
4. **迭代：** 重复步骤 2-3，直到质心变化小于阈值或达到最大迭代次数
5. **输出结果：** 输出每个数据点所属的簇及最终的质心位置

### PCA 主成分分析

PCA 通过正交变换将原始高维数据转换为一组线性无关的低维特征（主成分），保留数据的主要方差信息，同时降低计算复杂度。

### 轮廓系数

轮廓系数（Silhouette Score）综合衡量簇内紧密度与簇间分离度，取值 [-1, 1]，越接近 1 表示聚类效果越好。

## 实验流程

```
读取数据集
    │
移除 CUST_ID 列（因 ID 列导致解析报错）
    │
检查并处理缺失值（均值填充）
    │
生成 Pearson 相关性热力图
    │
PCA 主成分分析 + 累计方差图
    │
遍历 K=2~10，计算轮廓系数（K-Means 循环 20 次取最优）
    │
选定最优 K（本实验确定为 K=4，N_components=2）
    │
K-Means 聚类 + 二维散点图可视化
    │
输出各簇客户索引、人数统计、示例客户信息
```

## 使用说明

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 准备数据

将信用卡客户 CSV 文件放在与本脚本相同的目录下，或修改脚本中的 `DATA_PATH` 变量。

数据集应包含类似以下列：
- `CUST_ID`：客户唯一标识（将被移除）
- `BALANCE`：可用余额
- `PURCHASES`：总消费额
- `ONEOFF_PURCHASES`：一次性消费额
- `INSTALLMENTS_PURCHASES`：分期消费额
- `CREDIT_LIMIT`：信用卡额度
- 及其他客户行为特征

### 3. 运行实验

```bash
python 智慧金融数据挖掘_KMeans.py
```

运行完成后会在当前目录生成以下图片文件：
- `correlation_heatmap.png` — Pearson 相关性热力图
- `pca_cumulative_variance.png` — PCA 累计方差图
- `silhouette_scores.png` — 轮廓系数曲线
- `kmeans_clustering.png` — K-Means 聚类结果散点图

## 结果分析

### 参数调优过程

| PCA 主成分数 | 最佳 K | 轮廓系数 | 说明 |
|:---:|:---:|:---:|------|
| 2 | 4 | **0.5725** | 利于二维可视化，轮廓系数最高 |
| 3 | 6 | 0.4670 | 无法直接可视化 |
| 4 | 8 | 0.4429 | 过拟合风险增加 |
| 5 | 2 | 0.4470 | 解释度虽高但聚类效果下降 |

**最终选择：** PCA 保留 2 个主成分，K-Means 分为 4 个簇。

### 客户分群结果

| 簇 | 颜色 | 人数 | 特征描述 | 推荐关注度 |
|:---:|:---:|:---:|------|:---:|
| Cluster 0 | 红色 | 1726 | 可用余额高、额度高、余额变动频繁，**优质客户** | ⭐⭐⭐⭐⭐ |
| Cluster 3 | 青色 | 520 | 流水多、依赖分期还款、额度中等，**潜在客户** | ⭐⭐⭐⭐ |
| Cluster 2 | 绿色 | 23 | 额度高但使用频率低、可用余额少，**信誉较差** | ⭐⭐ |
| Cluster 1 | 蓝色 | 6367 | 经济状况一般、额度不高但使用频繁 | ⭐ |

### 银行策略建议

- **红色（Cluster 0）：** 绝对的大客户，信誉良好，应优先维护并提供高端服务。
- **青色（Cluster 3）：** 资金管理到位，需要提高信用额度，有成为优质客户的潜力。
- **绿色（Cluster 2）：** 可用余额过少，使用信用卡频率低，可考虑降低授信。
- **蓝色（Cluster 1）：** 消费活跃但额度有限，可适当提供额度提升服务。
