# 基于 VGG16 的垃圾图像分类识别系统

节能减排大赛参赛作品。基于深度学习 VGG16 网络结构，实现垃圾图像的七分类识别，并配套 PyQt5 交互式界面，支持用户上传图片实时预测。

---

## 项目概述

针对生活垃圾日益增多、居民分类意识不足的现状，本项目基于 VGG16 卷积神经网络，对垃圾图像进行七分类识别（纸类、塑料、金属、其他垃圾、玻璃、有害垃圾、厨余垃圾）。

数据集来源于 Kaggle 三个公开数据集，经筛选与平衡后每类 300 张，共 2100 张图像，以 8:2 划分训练集与测试集。

---

## 模型架构

```
输入图像 (224x224x3)
  |
  v
VGG16 特征提取层 (13 Conv + ReLU + Pooling)
  |    冻结预训练权重，不参与训练
  v
展平操作 (25088)
  |
  v
自定义全连接分类器：
  Linear(25088, 1024) -> ReLU -> Dropout(0.5)
  Linear(1024, 512)  -> ReLU -> Dropout(0.2)
  Linear(512, 256)   -> ReLU -> Dropout(0.2)
  Linear(256, 7)     -> Softmax
  |
  v
输出：7 类垃圾概率分布
```

## 训练结果

| 指标 | 数值 |
|------|------|
| 总体准确率 | 84.52% |
| 有害垃圾准确率 | 100% |
| 厨余垃圾准确率 | 100% |
| 塑料准确率 | 91.23% |
| 纸类准确率 | 83.33% |
| 金属准确率 | 77.59% |
| 玻璃准确率 | 60.94% |
| 交叉熵损失（末轮） | 0.0623 |

损失函数从首轮 0.8763 降至末轮 0.0623，模型收敛良好。

## 交互式界面

基于 PyQt5 构建，提供以下功能：
- 上传图片（支持常见图像格式）
- 一键识别并显示预测类别与置信度
- 预测结果图像标注（中文标注）
- 清除结果、退出确认等交互功能

## 个人贡献

本项目为该同学的独立全栈工作，具体包括：

- **数据查找**：在 Kaggle 平台上检索并筛选三个公开垃圾分类数据集，完成数据汇总与来源标注
- **数据清洗**：对原始数据进行去重、格式统一、类别平衡处理，每类固定 300 张，共 2100 张；在玻璃类中引入绿/棕色玻璃样本增加识别难度，防止过拟合
- **建立模型**：基于 PyTorch 实现 VGG16 网络结构，冻结特征提取层（迁移学习），设计三层全连接分类器，配置优化器与损失函数
- **调参**：对全连接层维度、Dropout 率（0.5/0.2）、批量大小（16）、初始学习率（0.001）等超参数进行迭代实验，确定最优配置
- **验证与结果输出**：输出 10 轮迭代的损失函数变化曲线、7 类垃圾的识别准确率、测试集可视化预测结果（84.52% 总体准确率）
- **交互式界面设计**：使用 PyQt5 独立开发桌面端图像识别系统，实现图片上传、实时预测、中文结果展示、置信度输出等完整交互流程
- **论文撰写**：独立完成 10 页项目说明书，涵盖研制背景、设计方案、实验结果、技术问题分析等完整章节
