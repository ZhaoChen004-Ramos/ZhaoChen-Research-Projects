## 项目简介

本实验使用 **LeNet** 卷积神经网络对 **MNIST** 手写数字数据集进行训练和测试，并对比了**平均池化**与**最大池化**对模型效果的影响。

LeNet 是由 Yann LeCun 于 1998 年提出的经典卷积神经网络，被广泛认为是深度学习卷积神经网络的奠基性工作之一，主要用于手写字符识别等图像分类任务。

## 网络结构

LeNet 结构包含两个卷积层（Conv）和三个全连接层（FC），交替使用池化层（Pool）进行下采样：

```
Input: (1, 28, 28)            # 单通道灰度图像
    │
Conv1:  5×5, 1→6              # 卷积核 5×5，输入通道 1 → 输出通道 6
    │
Pool1:  2×2, stride=2          # 平均池化 / 最大池化 → (6, 12, 12)
    │
Conv2:  5×5, 6→16             # 卷积核 5×5，输入通道 6 → 输出通道 16
    │
Pool2:  2×2, stride=2          # 平均池化 / 最大池化 → (16, 4, 4)
    │
Flatten: 16×4×4 → 256
    │
FC1:  256 → 120               # 全连接层 + ReLU
    │
FC2:  120 → 84                # 全连接层 + ReLU
    │
FC3:  84 → 10                 # 输出层（10 个数字类别）
```

### 关键参数

| 参数 | 值 |
|------|-------|
| batch_size | 128 |
| 优化器 | Adam (lr=0.001) |
| 损失函数 | CrossEntropyLoss |
| 训练轮次 | 10 |

## 实验结果与分析

### 损失曲线

- 交叉熵损失在 10 个 epoch 内持续下降，模型收敛效果较好。

### 识别准确率

- 可视化 10 张测试图像，原始模型（平均池化）的识别准确率为 **90%**（10 张中正确识别 9 张）。
- 唯一识别错误的是数字 "0"，可能原因是左上角的笔画连续性不够强，平均池化未能改善该区域的特征。

### 最大池化改进

- 将平均池化改为最大池化后，原本无法识别的 "0" 被正确识别。
- **原因分析：** 最大池化保留了局部区域中最显著的特征响应，使得数字的线条轮廓更宽、连续性更强，有助于捕捉边缘和角点等关键特征。

### 池化方式对比

| 池化方式 | 特点 | 适用场景 |
|----------|------|----------|
| 平均池化 | 保留区域平均值，更平滑，保留全局信息 | 语义分割等需要整体趋势的任务 |
| 最大池化 | 保留最强响应，突出边缘/角点，计算效率高 | 图像分类等需要显著特征的任务 |

## 思考题

### 1. 卷积层与全连接层的参数量差异

- **全连接层：** 每个神经元与上一层的所有神经元相连。例如 224×224×3 输入 → 1000 维输出，参数量约 1.5 亿。
- **卷积层：** 通过局部连接和权值共享大幅减少参数量。例如 3×3 卷积核，输入 3 通道 → 输出 64 通道，参数量仅 1792，相差可达 8 万倍。

### 2. 为什么卷积层的效果更好

- 局部感受野关注相邻像素的关联性
- 权值共享大幅减少参数量，防止过拟合
- 多通道分工明确，学习不同特征
- 保留二维空间结构，不丢失图像信息

### 3. 平均池化 vs 最大池化

- **平均池化：** 保留全局信息，更平滑，但对噪声敏感，可能弱化重要特征。
- **最大池化：** 突出显著特征，计算更快，但可能丢失细节信息。

### 4. 为什么需要 reshape 为 (N, 1, 28, 28)

- 适配卷积层的输入格式（batch, channels, height, width）
- 1 通道对应 MNIST 灰度图像
- 28×28 是 LeNet 的预期输入尺寸
- 保留空间结构，卷积层才能正确提取局部特征
