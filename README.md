## 各项目简介

### 1️⃣ 数学建模国赛
基于红外干涉法无损测量 SiC 外延层厚度。从薄膜干涉建模、菲涅尔公式折射率反演、随机森林预测到多光束干涉边界判定，构成完整求解管线。

### 2️⃣ 美国大学生数学建模 (MCM/ICM 2026)
基于戴维南等效电路和蒙特卡洛方法，建立锂电池连续时间 SOC 放电模型，量化电池寿命的不确定性。

### 3️⃣ 节能减排大赛
基于深度学习 VGG16 网络结构实现垃圾图像的七分类识别，配套 PyQt5 交互式界面，支持用户上传图片实时预测。

### 4️⃣ 部分深度学习项目
涵盖深度学习课程全部实验，从基础图像处理到 LeNet / AlexNet / VGG16 / Faster R-CNN / YOLOv5 / SiamFC / Pix2Pix / Segmentation 等 18 个实验脚本。

### 5️⃣ 智慧金融（机器学习）
使用 K-Means 聚类算法对银行信用卡客户数据进行聚类分析，结合 PCA 降维，通过轮廓系数确定最优分组，辅助银行筛选潜在客户。
