# 智能手机电池寿命建模与不确定性分析

MCM/ICM 2026 Problem A 完整建模方案。基于戴维南等效电路和蒙特卡洛方法，建立锂电池连续时间 SOC 放电模型。

---

## 项目概述

- **问题一**：戴维南等效电路 + 功率分解 + 阿伦尼乌斯温控内阻 → 连续时间 SOC 微分方程模型
- **问题二**：LSODA 求解器 + 蒙特卡洛 500 次采样 → 不同场景下关机时间预测
- **问题三**：7 参数局部灵敏度分析，推翻恒容量假设（Peukert + 温度修正）
- **问题四**：用户行为优化与 OS 级智能调优，考虑电池老化

---

## 代码管线

### 问题一
```
OCV-SOC 拟合 ← 马里兰数据集
功率分解 → 三模式功耗计算.py | 子功率趋势.py | 饼图.py
戴维南电路 → 极化电压绘图.py | 内阻趋势图.py | SOC-t 批量出图.py
```

### 问题二
```
实测数据 (deg5/25/40.xlsx) → 真实数据集曲线.py → 合并对比.py
蒙特卡洛模拟 (500次) → 关机时间分布 + 95% CI + 相关性
批量预测 9 场景 → 端电压分析关机时间.py
```

### 问题三
```
灵敏度分析.py → 7 参数局部扰动 → 排序：容量 > CPU > 网络
推翻恒容量假设.py → Peukert + 温度修正动态容量
```

### 问题四
```
可视化图表.py → 单变量优化柱状图：屏幕 +1.34h, CPU +1.22h, GPS +0.15h
```
